# FastAPI Learning Journey

A 14-day practical journey to learn FastAPI and build a real-world API project.

##  Goal

By the end of this learning journey, I aim to:

- Build REST APIs with FastAPI
- Understand routing, HTTP methods, and parameters
- Use Pydantic for data validation
- Work with databases
- Implement CRUD operations
- Handle errors properly
- Use dependency injection
- Implement authentication and authorization
- Write API tests with pytest
- Understand asynchronous programming
- Follow professional FastAPI project structure
- Build and document a real-world FastAPI project
